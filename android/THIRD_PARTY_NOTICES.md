Moon Launcher for Android includes the standalone Minecraft Java runtime based on ZalithLauncher2.

Source: https://github.com/ZalithLauncher/ZalithLauncher2
License: GNU General Public License v3.0 (GPL-3.0)

The runtime is built from pinned upstream source with the Moon application ID, name, version, and icon applied by android/rebrand-zalith.mjs. The source and build instructions are available from the linked repository and this Moon repository.
