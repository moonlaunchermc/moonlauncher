Noom Launcher for Android includes the standalone Minecraft Java runtime from Amethyst-Android.

Source: https://github.com/AngelAuraMC/Amethyst-Android/tree/330c6eae3164df64bdc4828e946a9e62cc5169e4
License: GNU Lesser General Public License v3.0 (LGPL-3.0)

The runtime is built from the pinned upstream source with the Noom application ID, name, version, and icon applied by android/rebrand-amethyst.mjs. The source and build instructions are available from the linked repository and this Noom repository.
